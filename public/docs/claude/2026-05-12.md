## ⚡ 開発効率を上げる実践Tips

### 1. CLAUDE.md でプロジェクトルールを固定する
```markdown
# プロジェクト名

## 技術スタック
- Next.js 16 App Router
- Tailwind CSS v4
- Neon Postgres（@neondatabase/serverless）

## コーディングルール
- コメントは書かない（コードで表現する）
- 型は明示的に書く
- push 前に必ず確認を取る
```
→ 毎回同じ指示を繰り返す手間がなくなる。チーム開発でも一貫性が保てる

---

### 2. サブエージェントで並列作業
```
「A機能とB機能を独立して調査してください」
→ 2つのAgentが並列で動くので、直列より2倍速い
```
→ 依存関係がないタスク（テスト書き・ドキュメント作成・調査）は並列化が有効

---

### 3. /compact で長期セッションを節約
長いセッションでコンテキストが溢れそうになったら `/compact` で圧縮。
重要な情報を保持したまま継続でき、コストも削減。

---

### 4. 大きなコードベースの読み込み方
```
「まず src/ 以下の構成を把握してください。次に auth 周りのファイルだけ詳しく読んでください」
```
→ 全部一度に渡すより、段階的に読ませた方が精度が高い

---

### 5. Think ツールで複雑な設計を解決
```
「この設計の問題点を深く考えてから、解決策を3つ提案してください」
```
→ 複雑なアーキテクチャ判断や、バグの根本原因分析に有効

## 🛠 個人開発者向け おすすめワークフロー

### 新機能開発の流れ
```
1. 仕様を自然言語で書いた .md ファイルを用意
2. Claude Code に「この仕様を実装してください」と渡す
3. 実装 → テスト → PR 作成まで一気に依頼
4. 自分はレビューのみ
```

### デバッグの流れ
```
1. エラーメッセージをそのまま貼る
2. 「このエラーの根本原因と修正方法を教えてください」
3. 修正コードを受け取って適用
```
