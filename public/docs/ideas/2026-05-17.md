# 個人開発アイデア分析 — 2026-05-17

> 廃サービスの難民・機能不足の高額アプリ — 既存市場の「穴」を突くアプリ5選

---

## 前提・今日の視点

今日のテーマは「既存サービスが作った空白を埋める」。サービス終了・値上げ・機能不足で離脱ユーザーが生まれた市場は、参入コストが低く初期ユーザー獲得がしやすい。海外→日本・日本→海外・高すぎる→安価の3パターンでそれぞれ具体例を出す。

---

### 🛫 1. 日本特化フライトトラッカー｜スコア: 80

**概要**
ANA・JAL・Peach・Jetstar など複数便を一画面で管理するフライト追跡アプリ。現在は各社アプリが分断されており、複数便を横断して確認できない。

**市場**
- ターゲット: 出張族・旅行好き（月2回以上搭乗する層）
- 参考: Flighty（海外製） — $47.99/year、App Store 4.8 ⭐、45,000+ レビュー
- 競合空白: Flighty は海外キャリア中心。ANA / JAL / Peach / Jetstar の日本 LCC に対応しておらず、日本語 UI もない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 1便のみ追跡 |
| モデル | 年額サブスクリプション |
| 価格 | ¥980/年（Flighty の約1/5） |

**主な機能**
- ANA・JAL・Peach・Jetstar・Spring Japan を横断追跡
- 遅延・ゲート変更をプッシュ通知
- 搭乗履歴の記録（旅程ログ）
- マイレージ残高の簡易表示（手動入力）

**AI活用**
- FlightAware API または AviationStack API でフライトデータ取得
- 遅延パターンの傾向分析（機材繰り・天候）を Claude API で解析してプッシュ通知文を生成

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Flighty | 低 | 日本 LCC 非対応、英語 UI のみ |
| ANA アプリ | 低 | ANA 便のみ |
| JAL アプリ | 低 | JAL 便のみ |
| Flightradar24 | 中 | リアルタイム追跡は優秀だが旅程管理機能なし |

**✅ 結論:** 海外→日本の典型例。API 統合がメインで難易度は中。¥980/年は心理的抵抗が低く継続率が見込める

### 💰 2. Mint 廃止後の空白を狙う — Zaim 海外版｜スコア: 82

**概要**
米国最大の家計簿アプリ Mint が 2023 年 12 月にサービス終了。1700 万ユーザーが代替を探している市場に、日本の家計簿アプリのノウハウを持ち込む。

**市場**
- ターゲット: 元 Mint ユーザー（25〜40 代、米国・英語圏）
- 参考: Zaim — 国内 1200 万ダウンロード、月額 ¥480、継続黒字経営
- 競合の価格: YNAB $109/year（機能は強いが学習コストが高い）、Monarch Money $99.99/year
- 競合空白: Mint の「自動連携 + 無料または低価格」の組み合わせが完全に空白になっている

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 手動入力・3口座まで連携 |
| モデル | 月額サブスクリプション |
| 価格 | $4.99/month（YNAB・Monarch の半額以下） |

**主な機能**
- Plaid API で米国銀行口座・クレジットカードの自動取得
- カテゴリ自動分類（AI で精度向上）
- 月別支出グラフ・予算設定
- サブスク一覧の自動検出（「知らずに払っているもの」を可視化）

**AI活用**
- 支出明細の自動カテゴリ分類（Claude Haiku でコスト抑制）
- 異常支出の検出（先月比 200% 超の項目を通知）
- 月次支出サマリーの自然言語生成

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| YNAB | 中 | $109/year と高額、学習コストが高い |
| Monarch Money | 中 | $99.99/year と高額 |
| Copilot | 中 | $59.99/year、iOS 専用 |
| NerdWallet | 低 | 広告モデル、UX が重い |

**✅ 結論:** Mint 難民は実在する大きな市場。Plaid API の初期コスト（月額 $500〜）が参入障壁になるが逆にモートにもなる。個人開発の初手より小チーム向き

### 📖 3. Readwise の半額代替 — 読書ハイライト管理アプリ｜スコア: 76

**概要**
Kindle・Kobo のハイライトを一元管理し、スペースドリペティションで復習できる Web アプリ。Readwise が高すぎると感じているユーザーの代替として。

**市場**
- ターゲット: 月 3 冊以上読む読書家（自己啓発・ビジネス書層）
- 参考: Readwise — $7.99/month（$95.88/year）。Reddit や X で「高い」「解約した」の声が多い
- 競合空白: Readwise Reader（$8.99/month）と合わせると $16.98/month。この価格帯を嫌うユーザーが離脱中

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 100 ハイライトまで・復習なし |
| モデル | 年額（買い切り感） |
| 価格 | $29/year（Readwise の約 3 割） |

**主な機能**
- Kindle ハイライト自動インポート（Amazon アカウント OAuth）
- Kobo 同期（USB 接続または API）
- スペースドリペティション（忘却曲線に合わせた復習タイミング通知）
- Obsidian / Notion エクスポート
- 物理本: OCR 撮影でハイライト登録

**AI活用**
- ハイライトから「今週の学びサマリー」を自動生成（Claude Haiku）
- 関連ハイライトの自動リンク（同じコンセプトが出てくるハイライトを束ねる）

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Readwise | 高 | 価格が高い、それが唯一の弱点 |
| Obsidian | 低 | 自動化がなく手動作業が多い |
| Notion | 低 | ハイライト特化機能なし |

**✅ 結論:** 「高すぎる市場」パターンの典型。Kindle API の制限が最大の技術的課題（非公式 API に依存するため利用規約リスクあり）

### 🗓 4. Structured → 日本版タイムブロッキングプランナー｜スコア: 85

**概要**
タイムライン形式で 1 日の予定をブロック表示する日本語タイムブロッキングアプリ。Structured の UX をベースに、日本ユーザー向けの機能を追加する。

**市場**
- ターゲット: タスク管理に悩む社会人・フリーランス（25〜45 歳）
- 参考: Structured — $39.99/year、App Store 4.8 ⭐、**80,000+ レビュー**、日本語 UI なし
- 競合空白: Google カレンダーはタスクのタイムブロッキングに弱い。Structured は日本語未対応で日本の祝日・六曜データもない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 1 日 5 タスクまで |
| モデル | 年額サブスクリプション |
| 価格 | ¥1,200/年（Structured の約 1/4） |

**主な機能**
- タイムライン UI（各タスクが時間帯に視覚的に並ぶ）
- Google カレンダー同期（予定をタイムブロックに変換）
- 日本の祝日・六曜・学校行事カレンダー対応
- 繰り返しタスクの自動配置
- ウィジェット（今日の残りタスクをホーム画面表示）

**AI活用**
- 「今日のタスクを時間割に組んで」で Claude が優先度を考慮して自動配置
- 過去の完了パターンから「このタスクは午前中に入れた方が終わりやすい」を提案

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Structured | 低 | 日本語なし、¥39.99/year と高め |
| Fantastical | 中 | カレンダー特化、タスク管理が弱い |
| Google カレンダー | 中 | 無料だがタイムブロッキング概念なし |
| Todoist | 中 | リスト形式、タイムライン UI なし |

**✅ 結論:** スコア最高位。日本語化 + 価格設定だけで差別化できる。React Native + Google カレンダー API で 3 ヶ月で MVP 可能。個人開発者が最も取り組みやすいアイデア

### 💬 5. Peing（質問箱）の海外版 — クリエイター向け匿名 Q&A｜スコア: 73

**概要**
X（Twitter）プロフィールにリンクを貼って匿名質問を受け付けるサービス。日本の Peing が月間 1500 万ユーザーを持つが海外展開なし。競合が相次いで課金化・廃止したため空白が生まれている。

**市場**
- ターゲット: X・Instagram・TikTok のクリエイター（フォロワー 1000〜10 万人規模）
- 参考: Peing — 月間 1500 万ユーザー、運営は Jibe 株式会社（日本）
- 競合の状況:
  - CuriousCat — 2022 年に突然有料化 → ユーザー大量離脱
  - NGL — スパム・偽通知問題で評判悪化（App Store レビュー 2.8 ⭐）
  - Formspring — 2013 年にサービス終了

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 匿名質問受付・返答（広告あり） |
| モデル | クリエイター向けサブスク |
| 価格 | $4.99/month（質問分析・広告非表示・返答補助 AI） |

**主な機能**
- X / Instagram / TikTok プロフィールに貼れるリンク 1 本
- 匿名質問の受付・返答
- 返答を X にワンクリック投稿
- 質問傾向の分析（どの投稿から質問が来たか）
- スパム質問の AI フィルタリング

**AI活用**
- スパム・嫌がらせ質問の自動検出（Claude Haiku でコスト抑制）
- 「この質問に対する回答案を 3 つ提示」（クリエイターの返答補助）

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| NGL | 中 | スパム問題・偽通知で信頼低下 |
| CuriousCat | 低 | 突然の有料化で信頼喪失 |
| Peing | 低 | 日本語のみ、海外展開なし |

**✅ 結論:** 海外競合が自滅した珍しい市場。スパム対策の品質が勝敗を分ける。Next.js + Vercel で構築しやすく初期コストが低い
