# アプリ戦略まとめ — 個人開発 × マネタイズ候補

> Claude Codeで爆速開発を前提とした、マネタイズ可能なアプリ候補の調査・分析まとめ

---

## 前提：App Store の基本知識

- Apple Developer Program: **年間$99**（約15,000円）
- Appleの手数料: 売上の**30%**（年間売上$1M以下の小規模開発者は**15%**）
- 審査期間: 通常**1〜3日**
- 課金はAppleのIn-App Purchase（外部決済は禁止）
- 買い切りアプリは全体の**約5%**、収益の98%は無料アプリから（フリーミアムが主流）

---

## 成功スコアの見方

| スコア | 評価 |
|--------|------|
| 85以上 | 強く推奨 — 競合空白×市場規模○ |
| 70〜84 | 推奨 — 差別化ポイントが明確 |
| 60〜69 | 条件付き — 強い差別化が必要 |

### 🌮 1. スペイン語レシピアプリ｜スコア: 88

**概要**
中南米・米国ヒスパニック向けに特化した料理アプリ。英語圏の大手（Allrecipes, Yummly）がスペイン語市場をほぼ放置している空白地帯を狙う。

**市場**
- スペイン語話者: 約**5億人**
- 米国内ヒスパニック: **6,000万人**（購買力が高い）
- ラテンアメリカ市場: 2025年時点**約1.6億ドル**、2033年には4.9億ドル予測

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | あり（基本レシピ無料） |
| モデル | フリーミアム + 買い切りパック |
| 価格 | 地域別プレミアムパック $1.99〜$2.99 |
| マネタイズポイント | メキシコ料理集・コロンビア料理集など地域別コンテンツパック |

**主な機能**
- スペイン語UIと音声読み上げ
- 地域別料理カテゴリ（メキシコ・ペルー・アルゼンチンなど）
- 材料リストからのショッピングリスト自動生成
- オフライン保存機能
- AIによる代替食材提案・栄養計算
- 家族人数に応じた分量スケール

**AI活用**
レシピ材料から代替食材を提案、栄養計算、冷蔵庫の余り食材からレシピ生成

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Allrecipes | 高 | 英語のみ・スペイン語UI弱 |
| Yummly | 中 | スペイン語コンテンツ薄い |
| ローカル競合 | 低 | デザイン・UXが古い |

**✅ 結論: 最も狙い目。競合空白×市場規模5億人**

### 📊 2. ハビットトラッカー（日本語×AI版）｜スコア: 85

**概要**
HabitKit（月33k USD稼ぐ海外個人開発アプリ）の弱点を全部補完した版。iCloud同期・AI分析・完全日本語対応を追加し、国内外で展開。

**HabitKitの弱点（差別化ポイント）**
- iCloud同期がない（ユーザーが最も求めている機能）
- Mac版が弱い
- AI機能がゼロ
- 日本語UIが完全対応していない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | あり（習慣4つまで） |
| モデル | 買い切り + アドオン |
| 価格 | 本体 $2.99 + テーマパック $0.99〜 |
| マネタイズポイント | 本体購入 + プレミアムテーマ・ウィジェットデザインのアドオン |

**主な機能**
- GitHubグリッド風の継続ビジュアライゼーション
- iCloud同期（HabitKitにない強み）
- ホーム画面ウィジェット（複数サイズ）
- 習慣の頻度設定（毎日・週N回・月N回）
- AI週間レポート・改善提案
- Year in Review（年間振り返り）
- カテゴリ分類・アーカイブ

**AI活用**
サボりがちな習慣の自動検出、週間レポート生成、最適なリマインダー時間の提案

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| HabitKit | 中 | iCloud同期なし・AI機能ゼロ |
| Streaks | 中 | iOS専用・高価格 |
| Habitify | 中 | 月額制・日本語UI弱 |
| 国産アプリ | 低 | デザインが古い |

**✅ 結論: HabitKitの弱点を潰せば勝てる。開発工数も少ない**

### 🍱 3. 日本食レシピ（英語圏向け）｜スコア: 82

**概要**
英語で本格的な和食レシピを提供。和食ブームは継続中だが専門アプリはほぼ空白。日本人開発者のコンテンツ面の強みが最大の差別化要因。

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | あり（基本レシピ無料） |
| モデル | フリーミアム + 買い切りパック |
| 価格 | 季節・テーマ別パック $1.99 |
| マネタイズポイント | 「本格だし・発酵食品・お正月料理」など季節コンテンツ |

**主な機能**
- 英語UIで本格和食レシピ（だし・発酵・麺類など）
- 入手困難な食材の代替案をAIが提案
- 調理難易度の段階表示
- オフライン保存
- 季節・行事別レシピカレンダー
- 計量単位の切り替え（グラム↔カップ）

**AI活用**
日本の食材が手に入らない場合の代替食材提案、難しい調理手順の解説

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Just One Cookbook | 中 | Webが強い・アプリが弱い |
| Japan Centre | 低 | 食材販売がメイン |
| 一般レシピアプリ | 低 | 和食コンテンツが薄い |

**✅ 結論: コンテンツが差別化要因。日本人開発者の圧倒的優位**

### 🏠 4. 家の持ち物管理アプリ｜スコア: 72

**概要**
断捨離・引越し需要が高い日本でまず磨き、英語展開する逆輸出モデル。AIカメラで写真を撮るだけで商品情報を自動入力するのが差別化の核。

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | あり（アイテム30件まで） |
| モデル | 買い切り |
| 価格 | $3.99（日本では¥600前後） |
| マネタイズポイント | 本体買い切り一本。シンプルな収益モデル |

**主な機能**
- 写真撮影でAIが商品名・カテゴリを自動入力
- 部屋・カテゴリ別の整理
- 断捨離モード（使用頻度でフィルタ）
- 引越しチェックリスト連携
- 不用品の推定市場価格表示
- iCloud同期・家族共有

**AI活用**
写真から商品名・カテゴリを自動認識、不用品の相場価格を提示

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Sortly | 中 | 月額制・企業向け寄り |
| Encircle | 低 | 保険向け・UIが古い |
| 国産アプリ | 低 | 機能が少ない |

**🟡 結論: AIカメラ入力が差別化の核。地味だが安定して売れる**

### 💳 5. サブスク管理アプリ（AI特化）｜スコア: 68

**概要**
スクショからAIが自動検出し解約ガイドも付いたサブスク管理アプリ。平均的なアメリカ人は月$219分のサブスクを契約しているが$86しか払っていないと思っている — このギャップが市場価値。

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | あり（サブスク3件まで） |
| モデル | フリーミアム + 月額サブスク |
| 価格 | $2.99/月 or $19.99/年 |
| マネタイズポイント | 無制限管理・AI自動検出・解約ガイドをプレミアム限定に |

**主な機能**
- スクショ・メールからAIがサブスクを自動検出
- 更新日前のプッシュ通知
- 月額・年額の合計ダッシュボード
- 解約手順のステップガイド
- 家族プラン最適化提案
- 通貨換算（海外サブスク対応）

**AI活用**
スクショ・メールからサブスクを自動検出、解約忘れアラート、最適プランの提案

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Bobby | 高 | デザイン強い・AI機能なし |
| ReSubs | 高 | 機能豊富・UI複雑 |
| Rocket Money | 中 | 銀行連携必須で敬遠される |

**🟡 結論: 市場はある。ただし競合が強くAI機能が必須条件**

### 🤖 6. AIウェルネスコンパニオン｜スコア: 65

**概要**
毎日話しかけるAIメンタルサポートアプリ。ARPUが最も高いカテゴリだが、Replicaなど強力な先行者がいる。

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | あり（1日5メッセージまで） |
| モデル | 月額サブスク |
| 価格 | $4.99/月 or $39.99/年 |
| マネタイズポイント | メッセージ数・音声会話・パーソナライズ深度をプレミアムで |

**主な機能**
- 毎日のチェックイン会話（テキスト・音声）
- 気分トラッキングとグラフ化
- AIによる感情分析・傾向レポート
- ジャーナリングのAI要約
- 呼吸法・マインドフルネスガイド
- 危機検知時の専門機関案内

**AI活用**
コアがAI。感情分析・パーソナライズ対話・気分トレンド分析

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Replika | 高 | 先行・認知度高い |
| Wysa | 高 | CBT特化・医療連携あり |
| Woebot | 中 | 学術的・若者向け |

**🔴 結論: ARPUは最高だが競合が最も強い。明確な差別化が必要**

-|------|

## 推奨アクションプラン

### 最短で収益化したいなら
**📊 ハビットトラッカー** から始める。
- 機能がシンプルで開発工数が最小
- HabitKitの弱点（iCloud同期・AI）を補うだけで差別化完成
- 日本語・英語両対応で最初からグローバル展開可能

### 最大の市場を狙うなら
**🌮 スペイン語レシピアプリ** を選ぶ。
- 競合空白地帯で5億人市場
- コンテンツさえ揃えれば参入障壁が高い
- メキシコにいる立地が活かせる

### 日本人開発者の強みを活かすなら
**🍱 日本食レシピ（英語圏向け）** が最適。
- コンテンツ面で圧倒的優位
- 英語圏に競合がほぼいない
- 和食ブームは長期継続トレンド
