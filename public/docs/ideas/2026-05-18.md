# 個人開発アイデア分析 — 2026-05-18

> ウィジェット・文章校正・睡眠・レシピ — 日常ツールの「ローカライズ空白」を狙う5選

---

## 前提・今日の視点

今日のテーマは「日常的に使うアプリのローカライズ不足」。海外では大ヒットしているのに、日本語対応が貧弱または存在しない市場。日本のユーザーが困っているのに代替がないジャンルを探す。逆に日本発の習慣・サービスを海外に持ち込むパターンも含める。

---

### 🧩 1. Widgetsmith → 日本語多機能ホームウィジェット｜スコア: 83

**概要**
iOS ホーム画面のウィジェットをカスタマイズするアプリ。海外の Widgetsmith をベースに、日本独自の情報（六曜・ゴミ収集日・電車遅延）を表示できる日本語版を作る。

**市場**
- ターゲット: iPhone ユーザー（日本国内 6,300 万台以上）、特に 20〜40 代
- 参考: Widgetsmith — **3,000 万ダウンロード以上**、App Store 4.7 ⭐、$1.99/month Premium
- 競合空白: Widgetsmith は日本語未対応。六曜・ゴミ収集日・市区町村別カレンダー連携が一切ない。日本製の代替アプリはデザイン品質が低い

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 基本ウィジェット3種・広告あり |
| モデル | 年額サブスクリプション |
| 価格 | ¥480/年（Widgetsmith の約4分の1） |

**主な機能**
- 六曜・旧暦・祝日を表示するカレンダーウィジェット
- ゴミ収集日ウィジェット（市区町村データを手動登録）
- 天気 + 花粉 + 紫外線 を1つのウィジェットで表示
- 電車遅延情報（Yahoo!路線 API）
- フォント・背景カラーのカスタマイズ

**AI活用**
- 「今日の六曜と天気から一言アドバイス」を Claude Haiku で生成してウィジェットに表示
- ゴミ収集日の自治体データをスクレイピング → 自動登録フロー

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Widgetsmith | 低 | 日本語・日本固有情報なし |
| WidgetKit 自作 | 低 | 個人が作れるが配布できない |
| めくり（日本製） | 中 | カレンダーに特化、天気・電車なし |

**✅ 結論:** 海外→日本の教科書例。React Native + WidgetKit でウィジェット実装が必要。難易度は中〜高だがユーザーの需要は明確

### ✍️ 2. Grammarly の日本語版 — AI 文章校正ツール｜スコア: 81

**概要**
日本語のビジネス文書・メール・ブログ文章を AI がリアルタイムで校正する Web アプリ + Chrome 拡張機能。Grammarly が英語圏で独占している市場の日本語版。

**市場**
- ターゲット: ビジネスメール・提案書を書く会社員、ブロガー、フリーライター
- 参考: Grammarly — **3,000 万 DAU**、$12/month Premium（個人）、$15/month Business
- 競合空白: 日本語の文章校正 SaaS は「文賢」（¥2,178/月）しかなく高い。ブラウザ拡張型がない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 基本的な誤字・読点の指摘のみ |
| モデル | 月額サブスクリプション |
| 価格 | ¥490/月（文賢の約4分の1） |

**主な機能**
- Chrome 拡張でどのサイトでも日本語校正
- 誤字・脱字・二重表現・冗長表現の指摘
- ビジネス文書向けトーン調整（「〜です」「〜ます」の統一）
- 敬語チェック（尊敬語・謙譲語の混同を検出）
- 文章の読みやすさスコア（文長・漢字密度）

**AI活用**
- Claude API で文章全体の文脈を理解した校正（単純な辞書マッチではなく意味を理解）
- ストリーミングでリアルタイム提案表示

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| 文賢 | 中 | ¥2,178/月と高い、Chrome 拡張なし |
| Grammarly | 低 | 日本語未対応 |
| JTF 校正ツール | 低 | 法人向け・UI が古い |
| Google ドキュメント校正 | 中 | 基本的な誤字のみ、敬語チェックなし |

**✅ 結論:** Claude API との相性が最も良いアイデアの一つ。Next.js Web + Chrome 拡張の2本立てで開発。Claude Haiku でコスト抑制しながら高品質な校正が可能

### 😴 3. Sleep Cycle → 日本版睡眠トラッカー｜スコア: 79

**概要**
睡眠サイクルを分析してベストな起床タイミングで目覚ましを鳴らすアプリ。海外の Sleep Cycle が持つ機能をベースに、日本のビジネスマン向けに残業・ストレス・睡眠負債の管理機能を追加する。

**市場**
- ターゲット: 睡眠に悩む会社員・30〜50 代（日本の睡眠不足率は先進国ワースト1位）
- 参考: Sleep Cycle — **$29.99/year**、App Store 4.6 ⭐、**1,000,000+ レビュー**（日本語未対応）
- 競合空白: Sleep Cycle は日本語 UI なし。日本製の睡眠アプリは単機能で分析が弱い

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 睡眠時間の記録・基本グラフ |
| モデル | 年額サブスクリプション |
| 価格 | ¥980/年（Sleep Cycle の約半額） |

**主な機能**
- マイク/加速度センサーで睡眠サイクル検出
- 浅い眠りのタイミングで起こすスマートアラーム
- 残業時間・睡眠時間の相関グラフ（手動入力）
- 睡眠負債の可視化（今週の不足時間を蓄積表示）
- 昼寝記録モード（15 分・20 分・90 分の推奨昼寝タイマー）

**AI活用**
- 睡眠パターンから「今日の疲労度」を推定して Claude API で一言アドバイス生成
- 週次レポートの自動生成

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Sleep Cycle | 低 | 日本語なし・高い |
| Sleepwatch | 低 | Apple Watch 専用 |
| みんびょう（日本製） | 低 | 睡眠特化ではなく健康全般 |
| Apple ヘルスケア | 中 | 記録できるがスマートアラームなし |

**✅ 結論:** 海外→日本の鉄板パターン。React Native の加速度センサー API で実装可能。マイクを使う睡眠分析は iOS のバックグラウンド制約に注意が必要

### 🍳 4. Cookpad の海外版 — 「家庭料理」特化レシピ SNS｜スコア: 75

**概要**
プロ・企業レシピではなく「家庭の人が作ったリアルなレシピ」に特化した英語圏向けレシピ投稿 SNS。Cookpad の「素人レシピが主役」というコンセプトを海外展開する。

**市場**
- ターゲット: 英語圏の家庭料理好き（米国・英国・オーストラリア）
- 参考: Cookpad — **9,000 万レシピ**（日本語）、月額 ¥178、月間 9,000 万ユーザー（グローバル版あるが普及していない）
- 競合空白: Allrecipes・Food Network はプロレシピが多い。「普通の家庭の人が今夜作ったもの」を投稿・検索するプラットフォームが英語圏にない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | レシピ投稿・閲覧・保存 |
| モデル | 広告 + プレミアム |
| 価格 | $2.99/month（広告非表示・材料費計算・買い物リスト連携） |

**主な機能**
- レシピ投稿（写真・手順・材料）
- 「今日の晩ご飯」タイムライン
- 材料からレシピ逆引き検索
- 「○○を使い切りたい」検索
- ユーザーフォロー・お気に入り

**AI活用**
- 材料写真を撮ると候補レシピを提案（Claude Vision）
- 「今ある材料でできるレシピ」を自然言語で検索

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Allrecipes | 中 | プロ・企業レシピ中心、家庭感がない |
| TikTok 料理動画 | 高 | 動画形式で強力、ただしレシピ保存が弱い |
| Cookpad Global | 中 | 日本発だが英語圏でのマーケティングが弱い |

**✅ 結論:** 日本→海外パターン。競合の TikTok に動画で対抗するより「テキスト+写真でレシピを保存・検索したい」層を狙う。Next.js + Vercel でフルスタック構築可能

### 🎁 5. ポイ活トラッカー海外版 — キャッシュバック一元管理アプリ｜スコア: 71

**概要**
クレジットカードのキャッシュバック・航空マイル・小売ポイントを一元管理するアプリ。日本の「ポイ活」文化を海外版に翻訳する。Mint 廃止後のポイント管理空白を埋める。

**市場**
- ターゲット: クレジットカードを複数枚持つ米国・英国ユーザー
- 参考: 日本の楽天ポイント経済圏（年間発行 **7,000 億ポイント以上**）。海外では統合型ポイントトラッカーが存在しない
- 競合空白: Mint が廃止されてからカード別キャッシュバックを一覧できるアプリがない。Chase・Amex・Capital One は各社アプリが分断

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 手動登録・3カード |
| モデル | 月額サブスク |
| 価格 | $2.99/month（自動同期・無制限カード） |

**主な機能**
- クレジットカードのキャッシュバック率を手動登録・比較
- カテゴリ別最適カード提案（「スーパーで一番還元率が高いカードは？」）
- 航空マイル残高の手動入力・有効期限アラート
- 月次ポイント獲得サマリー

**AI活用**
- 購入カテゴリに応じた最適カード推薦（Claude Haiku）
- 「今月ポイントをいくら獲得できた？」の自然言語レポート生成

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| AwardWallet | 中 | マイル特化、クレカキャッシュバック弱い |
| NerdWallet | 中 | カード比較サイト、ポイント管理機能なし |
| MaxRewards | 中 | Amex 特化で汎用性低い |

**✅ 結論:** 日本→海外のノウハウ転用。Plaid API（月額 $500〜）なしでも手動入力で MVP を作れる。小さく始められる点が個人開発者向け
