# 個人開発アイデア分析 — 2026-05-16

> 実在する成功アプリの弱点・空白地帯を突く。海外↔日本の往復で見えてくるニッチ5選。

---

## 前提：今日の分析軸

**既に「誰かが稼いでいる」が証明済みのカテゴリ**で、次の3つのパターンから選ぶ。

1. **海外で成功 × 日本版がない・弱い** → 日本語対応だけで差別化
2. **日本で成功 × 海外版がない** → 海外に持ち出す
3. **市場に成功アプリがあるが高すぎる** → 買い切り・低価格で奪う

個人開発者が Claude Code で 1〜3 ヶ月で MVP を出せる規模に絞る。

### 📦 1. 日本宅配便オールインワントラッカー｜スコア: 89

**概要**
ヤマト運輸・佐川急便・日本郵便・Amazon.co.jp の荷物を1画面で追跡できる iOS / Android アプリ。

海外では **Parcel**（iOS、年額 $9.99）が App Store 有料ランキング常連で、Amazon / USPS / FedEx を統合追跡して安定収益を得ている。日本版が**ない**。各キャリアの公式アプリはあるが、複数荷物を1アプリで見られるものは存在しない。

**市場**
- 国内宅配便取扱個数: **約50億個/年**（ヤマト・佐川・郵便の合計、国土交通省）
- EC 利用率の増加で荷物追跡ニーズは毎年拡大中
- Parcel のレビュー数: App Store で **2.5万件以上**（英語圏だけでこの数）

**競合空白**
- ヤマトの「クロネコメンバーズ」アプリ → ヤマトの荷物しか見られない
- 佐川の「スマートクラブ」→ 佐川のみ
- 日本郵便アプリ → 郵便のみ
- Amazon の通知 → Amazon 注文のみ、他社 EC は対象外

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 追跡件数3件まで |
| 買い切り | ¥600（$3.99）。無制限追跡 + ウィジェット |
| 将来 | 海外版（Parcel が攻めていない韓国・台湾）に横展開 |

**主な機能**
- 追跡番号を入力またはメール自動抽出でキャリアを自動判定
- 配達予定日のホーム画面ウィジェット（ロック画面対応）
- 配達完了プッシュ通知
- 「置き配済み」「保管中」などの状態を統一アイコンで表示
- 過去の配達履歴

**AI 活用**
メール本文・SMS から追跡番号を自動抽出（Claude Vision / 正規表現のハイブリッド）。「この番号はどのキャリア？」の自動判定。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| 各社公式アプリ | 低 | 自社荷物しか見られない |
| Parcel（海外） | 低 | 日本のキャリア API 未対応 |
| 宅配便ガイド系アプリ | 低 | 更新が止まっているものが多い |

**✅ 結論:** Parcel が証明済みの需要。日本語 + 国内キャリア対応だけで差別化完成。キャリアの追跡 API は一部非公開だがスクレイピングで代替可能。追跡番号フォーマットは公開情報で判定できる。

### 🤝 2. みんチャレ の英語版（グループ習慣トラッカー）｜スコア: 86

**概要**
5人グループで毎日写真を投稿して習慣を報告し合うアプリ。日本発の **みんチャレ**（2016年リリース、累計ダウンロード **300万件以上**）が持つ「仲間の目が継続力を生む」仕組みを英語圏に持ち込む。

英語圏の習慣アプリは Habitica・Streaks・HabitKit が強いが、**グループアカウンタビリティ × 写真証拠** の組み合わせを持つアプリはほぼない。

**市場**
- 英語圏の習慣トラッカーカテゴリ全体: App Store Productivity 上位の常連
- HabitKit が月 $33K を稼ぐカテゴリで、みんチャレの仕組みは HabitKit より粘着性が高い
- Beachbody / ランニングコーチ系コミュニティに需要あり（既存ユーザーベースに売れる）

**競合空白**
- Habitica: ゲーミフィケーション重視。写真報告なし。UI が複雑すぎて離脱が多い
- HabitKit: 個人完結型。グループ機能なし
- みんチャレ本体: 日本語のみ、英語対応なし

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | グループ1つまで・メンバー5人 |
| 買い切り | $3.99。グループ無制限 + カスタムテーマ |
| 月額 | $1.99/月（年払い $14.99）。写真ストレージ無制限 |

**主な機能**
- 最大5人のグループを作成、習慣の目標を設定
- 毎日写真を投稿して「達成」を報告（写真がないと未達成扱い）
- メンバーの投稿に絵文字でリアクション
- 連続日数・グループ全体の達成率グラフ
- 3日連続で投稿がない仲間へのプッシュ通知

**AI 活用**
「今日の写真を分析してちゃんと習慣できているか」を AI が判定（オプション）。週次レポートで「このグループは月曜に離脱しやすい」を分析。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Habitica | 中 | ゲーミフィケーション型。別カテゴリに近い |
| HabitKit | 低 | 個人完結型。グループなし |
| みんチャレ | 低 | 日本語のみ |
| Finch（自己ケアアプリ） | 低 | ウェルネス特化。グループ習慣ではない |

**✅ 結論:** みんチャレの「仲間の目」メカニックは再現性が高く、海外でも TikTok の「accountability partner」文化が広がっている。英語で作るだけで先行者優位。日本語版も同時に改良版として出せる。

### 🍳 3. Mela 型パーソナルレシピマネージャー（日本語版）｜スコア: 83

**概要**
Web サイトのレシピ URL を入力するだけで広告・余計な文章を削ぎ落として保存し、オフラインでも使える個人レシピ帳アプリ。

ドイツ発の **Mela**（iOS、買い切り $4.99）が欧米 App Store の料理カテゴリ有料ランキングで常連になっている。日本語対応は最小限で、クックパッド・デリッシュキッチンなどの日本の主要レシピサイトに対応していない。

**Mela の実績**
- 星5レビュー: App Store（US）で **5,000件以上**
- 定価 $4.99 の買い切りで長期間ランクイン（≒ 毎月安定した新規購入が続いている）

**市場**
- クックパッドの月間利用者: **約6,000万人**（日本最大）
- デリッシュキッチン・DELISH KITCHEN: 月間**数千万 PV**
- 日本の料理系 iOS アプリ市場: 大手サービスのアプリが占有しているが「自分だけのレシピ帳」特化はない

**競合空白**
- クックパッド・デリッシュキッチン: コンテンツサービス。レシピを保存する「器」ではない
- Mela 本体: 日本のレシピサイト（クックパッド・白ごはん.com など）のパーサーが未対応
- メモアプリ（Notion/メモ帳）: レシピ専用 UI がない、ステップ表示・タイマーがない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | レシピ10件まで保存 |
| 買い切り | ¥750（$4.99）。無制限保存 + iCloud 同期 |
| 将来 | Android 版展開（Mela は iOS 専用。そこが穴） |

**主な機能**
- クックパッド・白ごはん.com・デリッシュキッチンなど主要サイトの URL を貼るだけで保存
- 広告・ストーリー・余計なテキストを自動除去、レシピだけを抽出
- 調理中に画面が暗くならない「クッキングモード」
- 材料リストをタップするだけのステップバイステップ表示
- 食材からレシピ逆引き検索
- ホーム画面ウィジェット（今週のレシピ）

**AI 活用**
Claude で「この URL のレシピをパース → 材料リスト・手順を構造化データに変換」。対応していないサイトでも AI で汎用的にパースできるのが強み（Mela は専用パーサーが必要）。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Mela | 中 | iOS のみ・日本サイト未対応が穴 |
| クックパッドアプリ | 低 | 自社コンテンツのみ。外部URL保存なし |
| Paprika（レシピ管理） | 中 | 英語圏中心。日本語 UI なし |

**✅ 結論:** Mela の実績（$4.99 買い切りで 5,000 件超レビュー）は「このカテゴリに確実な需要がある」証拠。日本語 + 国内主要サイト対応 + Android 対応で Mela が取れていない市場をそのまま取れる。

### 📅 4. Fantastical の高額月額 → 買い切り日本特化カレンダー｜スコア: 77

**概要**
英語圏で最も人気の高機能カレンダーアプリ **Fantastical**（月額 $4.99、年額 $39.99）は日本市場でも評価が高いが、月額料金と日本固有の暦への対応不足がネック。旧暦・六曜・祝日表示を完備した買い切り版で価格感度の高い日本ユーザーを取り込む。

**Fantastical の弱点（日本ユーザーのレビューより）**
- 月額 $4.99 は日本のアプリ市場では高い（多くのユーザーが無料版に留まる）
- 六曜（大安・仏滅など）表示なし
- 旧暦表示なし
- 元号（令和）表示なし
- 日本の祝日データが遅れることがある

**市場**
- Fantastical の App Store レビュー数: **16万件以上**（有料アプリとして異例の数）
- 日本の Fantastical レビュー: 多数が「高すぎる」「六曜が欲しい」を指摘
- 純正カレンダーの代替を求めるユーザーは安定して存在

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | カレンダー閲覧のみ（追加・編集は不可） |
| 買い切り | ¥1,220（$7.99）。全機能 |
| 追加パック | ¥120 で六曜ウィジェット、旧暦ウィジェットなどを個別販売 |

**主な機能**
- 自然言語入力（「明日の14時に歯医者」で自動解析）
- 六曜・旧暦・元号（令和）表示
- 日本の祝日・振替休日の確実な対応
- ホーム画面・ロック画面ウィジェット（月表示・週表示・今日の予定）
- Google カレンダー・iCal 同期

**AI 活用**
「来週の空き時間を教えて」「3月に会議が多い日はどこ？」など自然言語でのカレンダー問い合わせ。スケジュールの自動整理提案。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Fantastical | 中 | 月額高い・日本固有暦なし |
| Calendars 5（Readdle） | 中 | 買い切り $6.99。六曜なし |
| 国産カレンダーアプリ | 低 | UI が古い・スマートウォッチ対応なし |
| 純正カレンダー | 低 | 機能不足。ウィジェットが弱い |

**✅ 結論:** 「高いから使わない」ユーザーを買い切り ¥1,220 で取る戦略。六曜・旧暦は日本特化の参入障壁になり、英語アプリが追いかけてこない。Widgetsmith（ウィジェット特化、無料 + IAP）が月 $50K 以上を稼ぐカテゴリでもある。

### 🧳 5. Splitwise × 日本の割り勘文化特化版｜スコア: 71

**概要**
割り勘精算アプリの世界標準 **Splitwise**（5,000万ユーザー、月額 $3.99）は日本で使いにくい。PayPay・LINE Pay・銀行振込での精算ガイドがなく、割り勘文化（飲み会・旅行）の日本的な文脈に合っていない。

**Splitwise の日本での問題点**
- PayPay・LINE Pay のリンク発行機能なし
- 「幹事が建て替えて後で回収」という日本の典型パターンを想定していないUI
- 英語UIが基本（日本語化が中途半端）
- 月額 $3.99 はカジュアル割り勘ユーザーには高い

**市場**
- Splitwise の MAU: **5,000万人以上**（うち日本ユーザーは少ない）
- 日本の飲み会・旅行での割り勘は年中発生する文化
- PayPay の月間決済ユーザー: **6,500万人以上**（2024年時点、PayPay 公式）

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 友人グループ3つまで・精算履歴3ヶ月 |
| 買い切り | ¥480（$2.99）。グループ無制限・履歴無制限 |
| 収益の柱 | 低価格買い切りで広く取る。PayPay 連携で口コミ拡散を狙う |

**主な機能**
- グループ作成 → 支払いを入力 → 誰がいくら払うか自動計算
- 「幹事払い一括→後で回収」パターンのワンタップ設定
- PayPay 送金リクエストリンクを自動生成（LINEで共有）
- 過去の飲み会・旅行のイベント別管理
- 精算完了ボタンで消込

**AI 活用**
「先週の飲み会でAさんが2,000円多く払ってるよ」「この旅行の精算で一番損してる人は？」を自然言語で表示。レシート写真から金額を自動入力。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Splitwise | 中 | 世界標準だが日本フィットしない |
| PayPay 割り勘 | 中 | PayPay ユーザー限定。履歴管理なし |
| Warikan（国産） | 低 | 機能がシンプルすぎる。更新が止まっている |
| LINE 割り勘 | 中 | LINE ユーザー限定。グループ精算が弱い |

**🟡 結論:** PayPay のリンク生成 × 日本の飲み会文化に特化するだけで Splitwise が取れていない市場が取れる。買い切り ¥480 は PayPay で1回チャージするより安い。口コミ拡散しやすい（幹事が送るだけで仲間全員がダウンロード）。

## 推奨アクションプラン

### 最短で App Store に出すなら
**1番（宅配便トラッカー）** が最速。追跡番号をスクレイプして UI で表示するだけの MVP は 1〜2 週間で作れる。Parcel が英語圏で証明した需要がそのまま使える。

### 長く稼ぎたいなら
**3番（Mela 型レシピマネージャー）** は「一度買ったら毎日使う」粘着性が高い。買い切り ¥750 は App Store で購入ハードルが低く、クックパッドのユーザーレビューで「URL 保存できるアプリ欲しい」の声が多い。

### グローバルを狙うなら
**2番（グループ習慣 英語版）** は英語圏でも TikTok の「accountability partner」文化で刺さる。日英同時リリースで日本語版（みんチャレの改良版）も出せる二正面作戦が可能。

## 技術スタック（React Native 前提）

```
フロントエンド: React Native（iOS / Android 同時開発）
DB（ローカル）: SQLite（expo-sqlite）+ MMKV（高速KVストア）
DB（クラウド）: Supabase（グループ機能が必要な 2・5番）
課金: RevenueCat（iOS / Android 両対応の課金管理）
AI: Claude API（Haiku 4.5 でコスト抑制）
プッシュ通知: Expo Notifications
スクレイピング: Cheerio / Puppeteer（宅配便・レシピ取得）
```
