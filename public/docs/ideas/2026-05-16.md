---

## 前提・今日の視点

今日のテーマは「AIネイティブ × 日本→海外」。従来のソフトウェアでは実現が難しかった、LLM があってはじめて成立するプロダクトに絞った。加えて、日本発で海外に通じる可能性があるアイデアを少なくとも1件含める。日本語の品質と文化的文脈の理解が武器になる領域に注目。

## 成功スコアの見方

- **90+** — すぐ着手すべき。市場・収益・技術的実現性がすべて揃っている
- **75〜89** — 有力候補。1〜2 つの懸念点をクリアできれば勝負になる
- **60〜74** — 参考まで。ニッチすぎる or 競合が強い

## 候補アプリ一覧（スコア順）

### 💬 1. コードレビュー AI アシスタント（GitHub 連携）｜スコア: 91

**概要**
GitHub の PR が作成・更新されると、Claude が自動でコードレビューコメントを投稿する GitHub App。セキュリティ・パフォーマンス・テスト漏れを指摘し、修正案のコードスニペットも提示する。個人・小チーム向けに月額 $9〜$29 で提供。

**市場**
- ターゲット: レビュアーが少ない個人開発者・スタートアップ（グローバル）
- 市場規模: GitHub の登録開発者は 1 億人超。有料リポジトリオーナーだけでも数千万人規模
- 競合空白: CodeRabbit・PR-Agent は存在するが、日本語ドキュメント・日本語コメントへの対応が弱い

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | パブリックリポジトリ無制限・プライベート月5PR |
| Pro | $9/月。プライベート無制限・1ユーザー |
| Team | $29/月（5名まで）。組織ルール設定・Slack 通知 |

**主な機能**
- PR 作成時に自動でインラインコメントを投稿
- セキュリティ（SQL インジェクション・XSS・認証ミス）を自動検出
- テストが書かれていないコードを指摘
- `REVIEW_RULES.md` をリポジトリに置くとプロジェクト固有のルールを適用
- 日本語・英語どちらのコメントにも対応

**AI 活用**
Claude に「PR の diff」「プロジェクトのコーディング規約」「過去のレビューコメントのパターン」を渡し、インラインコメントを生成。Prompt Caching でシステムプロンプトをキャッシュしてコストを削減。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| CodeRabbit | 高 | 機能が近い。ただし月額 $19〜。日本語弱い |
| GitHub Copilot PR Review | 高 | GitHub 公式。ただし Copilot セットが必要 |
| PR-Agent (OSS) | 中 | 自前ホスティングが必要で非エンジニアには難しい |

**✅ 結論:** 市場実証済み。差別化は「日本語品質」「安価な個人プラン $9」「REVIEW_RULES.md によるカスタマイズ」の3点。GitHub Marketplace に登録すれば発見されやすく、個人開発者には最速で検証できる題材。

### 📖 2. 技術ブログ × SNS 投稿 AI ライティングアシスタント｜スコア: 84

**概要**
エンジニアが「実装したこと・学んだこと」を箇条書きでメモすると、Zenn / Qiita の記事・X のスレッド・LinkedIn の投稿を自動生成する Web アプリ。「アウトプットしたいけど文章を書くのが苦手」な層がターゲット。日本→海外展開も可能。

**市場**
- ターゲット: 技術的な発信をしたいがアウトプットが苦手なエンジニア（日本・グローバル）
- 市場規模: 要調査（Zenn 登録者数・Qiita 登録者数は数十万人規模）
- 競合空白: 「エンジニア特化 × 複数プラットフォーム同時生成 × 日本語品質」の組み合わせがない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月5本まで |
| Pro | 月額 ¥980。無制限 + SEO最適化 + 下書き保存 |
| Team | 月額 ¥4,980（10名）。チームの発信を一元管理 |

**主な機能**
- 実装内容を箇条書きで入力 → Zenn / Qiita 向け記事（見出し・コードブロック付き）を生成
- 同じ内容から X スレッド（5〜7ツイート）を自動生成
- LinkedIn 向けの英語投稿も生成（日本→海外機能）
- コードスニペットを貼るとシンタックスハイライト付きのコードブロックに変換
- 過去の投稿からライティングスタイルを学習して再現

**AI 活用**
Claude に「メモ」「対象プラットフォーム」「ターゲット読者（初心者/中級者/上級者）」を渡し、媒体に最適化されたコンテンツを生成。「技術的に正確で、かつ読みやすい文体」を system prompt で固定。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Notion AI | 中 | 汎用ライティング。技術特化ではない |
| Buffer / Hootsuite | 低 | SNS 管理ツール。コンテンツ生成なし |
| ChatGPT | 中 | 汎用。プラットフォーム別最適化なし |

**✅ 結論:** 「エンジニアのアウトプット文化」は日本でも盛んになっており、需要は確実にある。¥980/月 × 1,000人 = 月収 ¥980,000 が現実的な目標。LinkedIn 英語投稿機能でグローバル展開の足がかりになる。

### 🎯 3. 採用候補者 AI スクリーニングツール（中小企業向け）｜スコア: 80

**概要**
求人票と応募者の職務経歴書を入力すると、Claude が「要件との適合度・懸念点・面接で確認すべき質問リスト」を自動生成する Web ツール。大手 ATS（Applicant Tracking System）を導入できない中小企業がターゲット。

**市場**
- ターゲット: 採用担当者が1〜2名しかいない中小企業・スタートアップ
- 市場規模: 要調査（国内の中小企業は約330万社。大半が ATS 未導入）
- 競合空白: 大手 ATS は高額（月額数万円〜）。個人〜中小向けの AI スクリーニングツールがない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月10件まで |
| Starter | 月額 ¥4,980。月100件・PDF出力 |
| Growth | 月額 ¥14,800。無制限・複数求人管理・Slack 通知 |

**主な機能**
- 求人票 + 職務経歴書（PDF / テキスト）を入力
- 必須要件・歓迎要件ごとの適合度スコアを 0〜100 で表示
- 「経験年数は足りているが、特定技術の言及がない」などの懸念点を自動抽出
- 候補者ごとに「面接で確認すべき質問リスト（5〜10項目）」を生成
- 複数候補者の比較表を自動生成

**AI 活用**
Claude に「求人票の要件」「職務経歴書」を渡し、要件ごとの適合度を分析させる。採用バイアスを減らすため「氏名・性別・年齢には触れず、スキルと経験のみで評価する」という制約を system prompt に明記。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Workday / SmartRecruiters | 低 | エンタープライズ向け。高額 |
| HireBase | 中 | 海外製。日本語対応が弱い |
| 求人媒体の自動マッチング | 中 | 媒体に依存。複数媒体をまたげない |

**✅ 結論:** 採用コスト（1人採用あたり数十万円〜）に比べると ¥4,980/月 は明らかに安い。採用担当者が「これがあれば書類選考が半日から2時間になる」と感じれば即解約率は低くなる。

### 🌍 4. 日本語 OSS → 英語ドキュメント自動生成ツール｜スコア: 74

**概要**
GitHub の日本語 README・コメント・コミットログを英語に翻訳・再構成し、国際的な OSS として通用するドキュメントセットを自動生成する Web ツール。「日本語で作ったが海外にも使ってもらいたい」OSS 開発者がターゲット。日本→海外の典型的な支援ツール。

**市場**
- ターゲット: 日本語で開発しているが海外展開を検討している OSS 開発者
- 市場規模: 要調査（GitHub 上の日本語リポジトリは数十万件規模）
- 競合空白: 「OSS ドキュメント特化 × 技術的正確性」の翻訳ツールはない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | パブリックリポジトリ無制限（OSS 支援） |
| Pro | 月額 $9。プライベートリポジトリ対応 |
| 将来 | GitHub Sponsors との連携（翻訳ドキュメントで海外スポンサーを獲得） |

**主な機能**
- GitHub リポジトリ URL を入力 → README・CONTRIBUTING・API ドキュメントを英語化
- コード内のコメント・変数名・コミットメッセージを英語に変換するPRを自動作成
- 英語 README のテンプレート（バッジ・インストール手順・使い方・コントリビューション）を自動補完
- 翻訳後のドキュメントをリポジトリに PR として提出

**AI 活用**
Claude に「日本語の技術文書」を渡し「海外の開発者に伝わる英語の OSS ドキュメント」に変換。単純翻訳ではなく「Getting Started / API Reference / Contributing Guide」の構造に再編集する。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| DeepL | 低 | 翻訳のみ。ドキュメント構造の再編成なし |
| ChatGPT | 中 | 汎用。GitHub 連携・PR 自動作成なし |

**✅ 結論:** OSS コミュニティへの貢献という文脈で口コミが広がりやすい。パブリックリポジトリ無料で認知を取り、プライベートリポジトリを有料化するモデルが自然。GitHub Marketplace でも展開できる。

### 🎮 5. 個人開発ゲーム × AI プレイガイド自動生成ツール｜スコア: 66

**概要**
Unity / Godot で作ったゲームのスクリーンショットとゲームデザインドキュメントを入力すると、Claude がプレイガイド・攻略 wiki の初稿・Steam ストアページの説明文を自動生成する Web ツール。個人ゲーム開発者がターゲット。

**市場**
- ターゲット: インディーゲーム開発者（Steam・itch.io へのリリースを目指している層）
- 市場規模: 要調査（Steam の新規リリース数は年間1万件超）
- 競合空白: 「ゲームドキュメント特化の AI ライティングツール」はほぼない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | プロジェクト1件まで |
| Pro | 月額 $7.99。無制限 + 多言語出力（英・日・中・韓） |
| 将来 | Steam / itch.io との直接連携 |

**主な機能**
- ゲームの設定・ストーリー・操作方法を入力 → Steam ストアページの説明文を生成
- スクリーンショットの説明文（ALT テキスト・キャプション）を自動生成
- 攻略 wiki の初稿（基本操作・アイテム一覧・FAQ）を生成
- 英語・日本語・中国語・韓国語の4言語で同時出力

**AI 活用**
Claude に「ゲームの世界観・キャラクター・操作感」を渡し、ゲームファンに刺さるマーケティングコピーを生成。「このゲームはどんな人に向いているか」を自然言語で分析させる機能も。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| ChatGPT | 中 | 汎用。ゲーム特化の最適化なし |
| Steam 公式サポート | 低 | ドキュメント作成支援なし |

**✅ 結論:** インディーゲーム開発者は1人で開発から宣伝まで担うため「ライティングに時間を使いたくない」ニーズが強い。$7.99/月 は安く、Steam ページの説明文1本を書く時間で元が取れる。ただし市場規模が小さいため大きな収益は見込みにくい。

## 推奨アクションプラン

### すぐ収益化したいなら
**1番（コードレビュー GitHub App）** が最速。GitHub Marketplace に公開すれば発見コストがゼロ。週末で MVP を作れる規模感。

### 日本市場で堅実に進めるなら
**3番（採用スクリーニング）** は単価が高く、1件契約が取れれば月 ¥4,980〜 の継続収益。知人の中小企業に声をかけてベータテストが最初のステップ。

### 日本→海外を一緒に狙うなら
**2番（技術ブログ AI ライター）** は英語版（LinkedIn 投稿生成）を同時に出せる。Product Hunt で英語圏にもリーチできる。
