## 候補アプリ一覧（スコア順）

### 🧾 1. 個人事業主向け AI 確定申告アシスタント｜スコア: 87

**概要**
領収書の写真を撮るだけで自動仕訳 → 確定申告書類の下書きを生成する Web アプリ。税理士費用を払えない個人事業主・フリーランスがターゲット。

**市場**
- ターゲット: フリーランス・個人事業主（日本に約 300 万人）
- 市場規模: 要調査（確定申告関連 SaaS は国内で急成長中）
- 競合空白: 既存ツール（freee・マネーフォワード）は月額 2,000〜3,000 円。「年 1 回だけ使いたい」層が未満足

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 領収書 20 枚まで・下書き生成のみ |
| 有料版 | 月額 980 円 or 年 5,980 円（確定申告期のみ使う想定） |
| 将来 | 税理士マッチング手数料（複雑なケースは税理士へ誘導） |

**主な機能**
- スマホカメラで領収書をスキャン → OCR + AI で科目を自動判定
- 事業・プライベートの按分を対話式で設定
- 青色申告・白色申告の切り替え対応
- 申告書 PDF の下書き出力

**AI 活用**
Claude で領収書の内容を読み取り、勘定科目を提案。「これは交通費ですか、それとも会議費ですか？」を自然言語で確認する対話フローを実装。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| freee | 高 | ブランド力大。ただし価格高め |
| マネーフォワード | 高 | 同上 |
| 弥生 | 中 | シニア層に強い。UI が古い |

**✅ 結論:** 「年 1 回だけ安く使いたい」層へのニッチ特化で freee と正面衝突を避けられる。確定申告シーズンに集中マーケティングで十分勝負できる。

### 🎙 2. 音声メモ → 構造化タスク変換アプリ｜スコア: 84

**概要**
「あ、あれやっておかないと」という思いつきを音声で録音すると、AI がタスク・期限・プロジェクトに自動分類して Notion / Linear / GitHub Issues に送ってくれるモバイルアプリ。

**市場**
- ターゲット: タスク管理ツールを使っているが入力が面倒な開発者・PM
- 市場規模: 要調査（タスク管理アプリ市場はグローバルで急成長）
- 競合空白: 音声入力 × 既存ツール連携の掛け合わせが少ない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月 30 件まで・Notion 連携のみ |
| Pro | 月額 $4.99。連携先無制限・無制限録音 |
| Team | 月額 $9.99/人。チーム共有・管理機能 |

**主な機能**
- ウィジェットからワンタップ録音開始
- Claude が内容を解析 → タスク名・期限・優先度を提案
- Notion / Linear / GitHub Issues / Todoist へ自動送信
- 「あとで確認」フォルダで未分類メモを管理

**AI 活用**
Whisper（音声認識）→ Claude でタスク構造化。「来週の月曜までに山田さんにデザイン確認メールを送る」を `{title: "山田さんへデザイン確認メール", due: "2026-05-18", assignee: "自分"}` に変換。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Siri リマインダー | 中 | 連携先が少ない |
| Otter.ai | 低 | 議事録特化。タスク変換はない |
| Notion AI | 中 | Notion 内のみ。クロスツールではない |

**✅ 結論:** 連携先の豊富さと「ゼロ摩擦の入力」が差別化。グローバル展開できる。開発者向け SNS（X・Zenn）での口コミが取りやすい。

### 🇯🇵 3. 外国人エンジニア向け日本就職ガイドアプリ｜スコア: 81

**概要**
日本で働きたい海外エンジニアが、ビザ・給与水準・企業文化・面接準備を AI と対話しながら学べる英語の Web アプリ。日本→海外の視点。

**市場**
- ターゲット: 日本就職を目指す東南アジア・東欧・南米のエンジニア
- 市場規模: 要調査（IT 人材不足で企業の外国人採用意欲は高まっている）
- 競合空白: 日本就職特化の英語コンテンツは圧倒的に不足

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | ガイドコンテンツ閲覧のみ |
| Pro | 月額 $9.99。AI 面接練習・履歴書添削・企業マッチング |
| 企業向け | 採用掲載料。外国人エンジニアへの求人掲載 $500〜/月 |

**主な機能**
- ビザ種別（技術・人文知識）の要件をわかりやすく解説
- 日本企業の面接文化（自己紹介・志望動機の作法）をロールプレイで練習
- 給与交渉のシミュレーション（日本は交渉が少ない文化の説明含む）
- 「この企業は外国人フレンドリーか」をクチコミで判定

**AI 活用**
Claude と英語で面接練習。「Tell me about yourself」に対して日本企業的な回答の良し悪しをフィードバック。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Glassdoor | 低 | 日本情報は少ない |
| 外務省ガイド | 低 | 静的コンテンツのみ |
| TokyoDev | 中 | コンテンツ特化。AI 機能なし |

**✅ 結論:** 企業側の採用課題（外国人エンジニア不足）と個人の就職課題を同時に解決できる両面市場。英語コンテンツなのでSEO流入も期待できる。

### 📊 4. GitHub リポジトリ技術負債スコアラー｜スコア: 73

**概要**
GitHub リポジトリの URL を入力するだけで、技術負債・セキュリティリスク・依存関係の陳腐化を自動スコアリングして可視化する Web ツール。

**市場**
- ターゲット: OSS 貢献者・採用担当者（候補者のコードを評価したい）・個人開発者
- 市場規模: 要調査
- 競合空白: 無料でサクッと使える「外部から見るリポジトリ評価ツール」が少ない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | public リポジトリ 5 件/月まで |
| Pro | 月額 $8。無制限・private リポジトリ対応 |
| 採用プラン | 月額 $49。候補者コード評価レポートを PDF 出力 |

**主な機能**
- 依存関係の最終更新日・CVE（脆弱性）を自動チェック
- コードの複雑度・テストカバレッジ推定
- 「このリポジトリの健全度スコア」を 100 点満点で表示
- 改善提案をランキング形式で提示

**AI 活用**
Claude がコードサンプルを読んで「ここは将来的に問題になりそう」という定性的なフィードバックを生成。スコアだけでなく文章での説明を追加。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| Snyk | 高 | セキュリティ特化で強力 |
| SonarQube | 高 | エンタープライズ向け。個人には重い |
| CodeClimate | 中 | CI/CD 連携メイン |

**✅ 結論:** 競合は強いが「URL 貼るだけでサクッと使える無料版」というUXの差別化余地あり。採用ツールとしての副需要が面白い。

### 🍱 5. 日本食レシピ × 栄養管理アプリ（英語圏向け）｜スコア: 68

**概要**
英語圏で日本食に興味があるユーザー向けに、本格的な和食レシピと栄養計算を組み合わせたアプリ。「ラーメンもヘルシーに食べたい」需要に応える。海外→日本の視点。

**市場**
- ターゲット: 日本食ファンの欧米ユーザー（30〜45 歳の健康意識高め層）
- 市場規模: 要調査（海外での日本食人気は継続中）
- 競合空白: 和食特化の栄養管理アプリはほぼ存在しない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | レシピ閲覧・基本栄養計算 |
| Pro | 月額 $4.99。カスタム食事プラン・代替食材提案 |
| 将来 | 日本食材の海外通販との提携（アフィリエイト） |

**主な機能**
- 400 種類以上の和食レシピ（海外で入手しやすい食材で代替提案）
- 栄養素の自動計算（和食の特徴である出汁・発酵食品の解説付き）
- 「今週の和食チャレンジ」で継続率を上げるゲーミフィケーション
- 食材が手に入らないときの代替提案（例：みりん → rice wine + sugar）

**AI 活用**
冷蔵庫にある食材を入力すると Claude が和食レシピを提案。「玉ねぎ・卵・だし（代替可）があります」→「親子丼が作れます。だしは chicken stock で代替できます」。

**競合分析**
| 競合 | 脅威 | 備考 |
|------|------|------|
| MyFitnessPal | 中 | 和食データが不正確 |
| Noom | 低 | 和食特化ではない |
| Just One Cookbook | 中 | レシピブログ。アプリ機能なし |

**✅ 結論:** 競合が少ないニッチだが市場規模が読みにくい。副業として始めて、App Store の自然流入を試す価値はある。
