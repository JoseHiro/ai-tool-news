## 前提・今日の視点

今日のテーマは「情報の整理・記録・共有」ツールのローカライズとコスト削減。読書ログ・動画共有・タスク管理という日常的に使う分野で、海外ツールが高価だったり日本語対応が不十分だったりする領域を狙う。

### 📖 1. Readwise → 日本語電子書籍ハイライト管理アプリ｜スコア: 85

**概要**
Kindle・Kobo などの電子書籍のハイライトを自動収集し、忘却曲線に基づいた復習通知を送るアプリ。Readwise が Amazon JP の仕様差により対応できていない日本語書籍市場に参入する。

**市場**
- ターゲット: 電子書籍ユーザー（日本の電子書籍市場 2024 年: 約 **6,900 億円**、前年比 8% 増）
- 参考: Readwise — **$7.99/month**、Twitter・Kindle など **20+ プラットフォーム**対応、2022 年時点で MRR $500k 超（IndieHackers 掲載）
- 競合空白: Readwise は Amazon JP の Kindle ハイライトを取得できない（Amazon JP の API 仕様の違いによる）。日本語書籍に特化した代替アプリが存在しない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 直近 3 冊のハイライト管理・1 日 1 件の復習通知 |
| モデル | 月額サブスクリプション |
| 価格 | ¥490/月（Readwise より約 $1 安く設定） |

**主な機能**
- Amazon JP の Kindle ハイライトページを自動同期（スクレイピング）
- 忘却曲線（SuperMemo SM-2 アルゴリズム）に基づく毎日の復習通知
- ハイライトへのメモ・タグ追加
- Obsidian / Notion へのエクスポート
- 読書ログ（読んだ冊数・ジャンル分布）

**AI活用**
- Claude Haiku でハイライトの要約を自動生成（「この本のポイント3行で」）
- 関連するハイライト同士をベクトル検索でクラスタリング
- 「このハイライトを今の仕事にどう活かせるか？」を Claude Sonnet で提案

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Readwise | 低 | Amazon JP Kindle のハイライト取得不可 |
| ブクログ | 中 | 読書記録特化、ハイライト復習機能なし |
| Notion テンプレート | 低 | 手動コピーが必要、自動同期なし |
| Obsidian | 低 | 設定が複雑、一般ユーザー向けではない |

**✅ 結論:** 海外→日本の明確な穴。Amazon JP ハイライートページのスクレイピングが技術的核心（可否は要調査）。¥490/月 × 1,000 ユーザー = 月 49 万円の収益が見えやすい。先行者がいない今が参入タイミング

### 🎬 2. Loom の安価日本語版 — AI 画面録画 + 自動要約ツール｜スコア: 82

**概要**
画面録画動画を AI が自動で文字起こし・要約・チャプター分割する Web アプリ。Loom が $8/月〜と高く日本語文字起こし精度が低い問題を、日本語特化・低価格で解決する。

**市場**
- ターゲット: リモートワーカー・フリーランス・SaaS のカスタマーサクセス担当
- 参考: Loom — **$8/month Starter**、2023 年 Atlassian が **$975M** で買収、ユーザー数 **2,500 万人以上**（公式）
- 競合空白: Loom の日本語文字起こし精度は低い（Whisper 未使用）。日本語特化の画面録画 + AI 要約ツールが存在しない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月 5 件まで・5 分以内・要約 3 件 |
| モデル | 月額サブスクリプション |
| 価格 | ¥490/月（Loom Starter の約 5 分の 1） |

**主な機能**
- ブラウザ拡張または Electron デスクトップアプリで画面録画
- Whisper large-v3 で日本語文字起こし（精度 95%+）
- Claude Haiku で要約・チャプタータイトルの自動生成
- 動画 URL 共有・コメント機能
- Slack / Notion への埋め込みリンク生成

**AI活用**
- Whisper large-v3 で文字起こし（$0.006/分）
- Claude Haiku で要約・チャプタータイトル生成（1 動画あたり約 $0.003）
- 「この動画について質問する」チャット機能

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Loom | 中 | 日本語文字起こし精度が低い・$8/月〜 |
| Claap | 中 | 英語のみ |
| tl;dv | 中 | 会議録画特化、画面録画なし |
| QuickTime + YouTube | 低 | AI 要約・文字起こしなし |

**✅ 結論:** 高すぎる→安価代替パターン。Whisper + Claude Haiku のコスト構造で 1 動画あたり $0.01 未満で処理できる。Next.js + FFmpeg（WebAssembly）+ Vercel でフルスタック実装可能

### 🏠 3. 家事タスク分担アプリ — Tody の日本語強化版｜スコア: 78

**概要**
家の掃除・洗濯・料理などの家事を頻度と担当者を設定して管理するアプリ。海外の Tody を参考に、日本の家事分担（ゴミ出し・浴室掃除・粗大ゴミ申請）に特化した機能を追加する。

**市場**
- ターゲット: 共働きカップル・夫婦（日本の共働き世帯 2024 年: 約 **1,278 万世帯**）
- 参考: Tody — **App Store 4.7 ⭐**、$1.99/month Pro、ダウンロード数は要調査（英語圏人気）
- 競合空白: Tody は日本語未対応。日本製の「OurHome」が有名だが、通知機能が弱くカスタムタスク（粗大ゴミ申請日・地域固有の家事）に対応していない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 1 世帯・タスク 10 件まで |
| モデル | 買い切り or 年額 |
| 価格 | ¥370 買い切り or ¥490/年（写真記録・リマインダー強化） |

**主な機能**
- 家事タスク登録（名前・頻度・担当者・最終実施日）
- 「今週やること」ダッシュボード
- パートナーとリアルタイム共有
- ゴミ出し日カレンダー連携（市区町村データを手動登録）
- 家事完了の写真記録（「ちゃんとやった証拠」機能）

**AI活用**
- Claude Haiku で「今週やるべき家事の優先順位」を自動提案
- 「最近どっちが多く家事してる？」の自然言語レポート生成

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| OurHome | 高 | 日本製で強い。通知機能・カスタムタスクが弱い |
| Tody | 低 | 日本語なし・日本固有タスクなし |
| Google Tasks | 低 | 共有・頻度設定・写真記録なし |

**✅ 結論:** 海外→日本の定番パターン。OurHome との差別化は「完了写真記録」と「AI 優先順位提案」。React Native で iOS/Android 同時リリース必須。夫婦間の家事問題という強い痛みがある

### 📊 4. スプレッドシート → Notion DB 自動変換ツール｜スコア: 74

**概要**
Excel / Google Sheets のデータを Notion データベースに AI が構造を解析しながら移行する Web アプリ。手動でのコピーペーストと型設定の手間を自動化する。

**市場**
- ターゲット: Notion に移行しようとしているスタートアップ・個人事業主
- 参考: Notion — **$8/user/month Plus**、**4,000 万ユーザー以上**（2022 年公式）。日本の Notion ユーザー数は要調査
- 競合空白: Notion 公式インポートはあるが、列の型（日付・セレクト・チェックボックス）を自動判定しない。インポート後に手動で型を設定し直す手間がかかる

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 100 行まで・1 回/日 |
| モデル | 月額 or 従量課金 |
| 価格 | ¥490/月（無制限）or ¥10/変換（従量） |

**主な機能**
- CSV / Excel ファイルアップロード または Google Sheets URL 入力
- Claude Haiku による列の型自動判定（日付・URL・数値・セレクト・チェックボックス）
- Notion API で自動インポート（OAuth 認証）
- インポート前のプレビュー確認
- 繰り返しインポートのスケジュール設定

**AI活用**
- Claude Haiku で列ヘッダーと値から型を推定（「2026/01/15」→ Date、「○/✓」→ Checkbox）
- スキーマの命名規則を統一（日本語カラム名 → スネークケース英語など）

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Notion 公式インポート | 中 | 型の自動判定なし |
| Coupler.io | 中 | $49/月と高い・設定が複雑 |
| Zapier | 中 | 設定が複雑・高価 |

**✅ 結論:** 高すぎる→安価代替パターン。Notion API + Claude Haiku のシンプルな組み合わせで MVP が作れる。Next.js の API Route だけで完結するシンプルな構成。小さく始めて Airtable 対応などに拡張できる

### 🌏 5. 日本語ポッドキャスト → 英語字幕自動生成ツール｜スコア: 70

**概要**
日本語ポッドキャストや動画に英語字幕を自動生成して、海外発信を支援する Web サービス。日本語コンテンツの「ガラパゴス化」を低コストで解決する。

**市場**
- ターゲット: 海外発信を考えている日本の個人ポッドキャスター・YouTuber
- 参考: Rev.com — $1.5/分（人力英語字幕）、Descript — **$24/month**（英語のみ対応）
- 競合空白: 日本語→英語の字幕自動生成は Whisper + DeepL の組み合わせで実現できるが、まとめて提供する SaaS がない。個人が英語字幕を付けようとすると手作業か高額なツールしか選択肢がない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月 10 分まで |
| モデル | 従量課金 |
| 価格 | ¥10/分（Rev.com の人力字幕の約 7 分の 1） |

**主な機能**
- MP3 / MP4 アップロードで日本語音声を文字起こし（Whisper）
- DeepL API で英語翻訳
- SRT / VTT 字幕ファイルのエクスポート
- YouTube 向けキャプションファイルの直接出力
- ポッドキャストプレーヤーへの埋め込みスクリプト

**AI活用**
- OpenAI Whisper で日本語文字起こし
- DeepL + Claude Sonnet でポッドキャスト特有の話し言葉・専門用語を自然な英語に補正

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Rev.com | 低 | 人力・高額（$1.5/分）・納期 1 日〜 |
| Descript | 低 | 英語のみ |
| VEED.io | 中 | 日本語→英語の精度が低い |

**✅ 結論:** 日本→海外パターンのニッチ版。市場規模は小さいが競合が薄い。Whisper + DeepL API の組み合わせで個人が 1 週間で MVP を作れる規模。¥10/分で採算が取れる
