# 個人開発アイデア分析 — 2026-05-20

> 議事録自動化・断捨離支援・日程調整 — 「時間とモノの管理」ツールのローカライズ空白

## 前提・今日の視点

今日のテーマは「時間・会議・モノの管理」。リモートワーク時代に必須なのに日本語対応が弱かったり価格が高すぎたりするツールを狙う。特に「会議の記録」「不用品の処分」「日程調整」という日常的な痛みに絞る。

---

### 🎙️ 1. Otter.ai → 日本語議事録自動生成 SaaS｜スコア: 87

**概要**
Web 会議（Zoom・Teams・Google Meet）に自動で bot 参加して、日本語の文字起こし・要約・アクションアイテムの抽出を行う SaaS。Otter.ai が英語圏で独占している市場の日本語特化版。

**市場**
- ターゲット: リモート会議が週 5 回以上ある会社員・フリーランス
- 参考: Otter.ai — **$8.33/month Pro**、月間 **300 万ユーザー**（2023 年公式）、$16.99/month Business
- 競合空白: Otter.ai は日本語未対応。日本語議事録 SaaS「Notta」は $22.67/月〜、「tl;dv」は $29/月と高価。¥490 以下の選択肢がない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月 3 回まで・30 分以内・要約 1 件 |
| モデル | 月額サブスクリプション |
| 価格 | ¥490/月（Notta の約 4 分の 1） |

**主な機能**
- Zoom / Google Meet に bot として自動参加
- Whisper large-v3 で日本語文字起こし（精度 95%+）
- Claude Sonnet でアクションアイテム・決定事項・次回議題を構造化抽出
- 参加者別発言時間のグラフ
- Slack / Notion への自動投稿

**AI活用**
- Whisper large-v3 で文字起こし（$0.006/分）
- Claude Sonnet で「決定事項」「TODO」「次回議題」を JSON で抽出
- 「この会議の目的は達成されたか？」の自動評価（Claude Haiku）

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Notta | 高 | $22.67/月〜と高い・UI が複雑 |
| tl;dv | 中 | 日本語精度が低い・$29/月 |
| Otter.ai | 低 | 日本語未対応 |
| Zoom AI Companion | 中 | Zoom 限定・有料プランのみ |

**✅ 結論:** 海外→日本の明確な価格差。Whisper + Claude のコストは 1 会議（60 分）あたり $0.36 + $0.03 = 約 $0.40。¥490/月 × 2,000 ユーザー = 月 98 万円の収益ラインが見える。Zoom SDK の bot 実装が技術的核心で、これが参入障壁にもなる

### 📦 2. 断捨離 × フリマ出品支援アプリ — 「捨て活」自動化｜スコア: 81

**概要**
部屋の物を写真で撮ると AI が自動でフリマアプリ（メルカリ・ラクマ）の出品文・推奨価格を生成するアプリ。「捨てたいけど出品が面倒」という障壁を AI で取り除く。

**市場**
- ターゲット: 断捨離・引越しをしたい 20〜40 代
- 参考: メルカリ — **月間 2,200 万 MAU**（2024 年決算）。フリマ市場規模 **約 1.2 兆円**（2024 年）
- 競合空白: メルカリ公式 AI は「カテゴリ提案のみ」で出品文全体は生成しない。写真 1 枚から完全な出品文を生成するスタンドアロンアプリが存在しない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月 5 件まで・基本テンプレート |
| モデル | 月額 or 買い切り |
| 価格 | ¥490/月（無制限）or ¥370 買い切り（10 件/月） |

**主な機能**
- カメラ撮影 → 商品名・状態・カテゴリを自動判定（Claude Vision）
- メルカリ・ラクマの相場を参照した推奨価格提案（要調査: スクレイピング可否）
- 出品文の自動生成（商品の特徴・サイズ・注意事項）
- ワンタップでメルカリアプリに内容をコピー
- 出品した商品の管理ダッシュボード

**AI活用**
- Claude Vision（Sonnet）で商品の状態・ブランド・カテゴリを判定
- Claude Haiku で出品文生成（1 件あたり $0.002 以下）
- 過去の出品データから「この時間帯・曜日に出品すると売れやすい」を提案

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| メルカリ公式 AI | 高 | カテゴリ提案のみ・出品文全体は生成しない |
| ラクサス | 低 | ブランド品特化 |
| オークファン | 中 | 価格調査特化・出品文生成なし |

**✅ 結論:** 日本市場特化の高需要案件。メルカリの「出品が面倒」という明確な痛みがある。React Native + Claude Vision で個人が 1〜2 ヶ月で MVP を出せる規模

### 📅 3. Calendly の日本語特化版 — 日程調整 + リマインダー自動化｜スコア: 77

**概要**
自分の空き時間を URL で共有して相手に予約させる日程調整ツール。Calendly の日本語特化版として、ビジネスマナーに合った確認メールの文面生成と日本の祝日の自動ブロックを実現する。

**市場**
- ターゲット: フリーランス・営業担当・コーチ・カウンセラー（予約管理に時間を使いたくない人）
- 参考: Calendly — **$10/month Essentials**、**1,000 万以上のユーザー**。日本語 UI はあるが「敬語が不自然」「日本の祝日設定が手動」というレビューが多い
- 競合空白: TimeRex は日本製で強いが、Zoom URL 自動生成・自動リマインダーが有料プラン限定（¥2,000/月〜）

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 予約ページ 1 種類・月 10 件まで |
| モデル | 月額サブスクリプション |
| 価格 | ¥490/月（Calendly の約 3 分の 1、TimeRex の約 4 分の 1） |

**主な機能**
- Google Calendar 連携（空き時間の自動検出）
- 予約確認・リマインダーメールの自動送信（Resend）
- Zoom URL の自動生成・メール挿入
- 日本の祝日の自動ブロック（内閣府 API 連携）
- 「ビジネス敬語モード」（確認メールを丁寧語に統一）

**AI活用**
- Claude Haiku で予約確認・リマインダーメールを相手に合わせた敬語で自動生成
- 「先週の予約キャンセル率が高かった時間帯は？」の分析レポート

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Calendly | 中 | 日本語が不自然・祝日設定が手動 |
| TimeRex | 高 | 日本製で強い。Zoom 自動生成・リマインダーが有料プランのみ |
| 調整さん | 低 | 自動リマインダー・カレンダー連携なし |

**✅ 結論:** 高すぎる→安価代替パターン。TimeRex の機能を ¥490/月で提供すれば明確な差別化になる。Next.js + Google Calendar API + Resend でシンプルに実装可能

### 🔑 4. パスワードレス認証 SaaS — Magic Link 特化｜スコア: 73

**概要**
Magic Link（メールに認証リンクを送るパスワードレス認証）をどんな Web アプリにも 1 行で追加できる認証 SaaS。Auth0 / Clerk の代替として個人開発者向けに低価格で提供する。

**市場**
- ターゲット: 認証実装を自前でしたくない個人開発者・スタートアップ
- 参考: Auth0 — **$23/month Essentials**（1,000 MAU）、Okta が $6.5B で買収。Clerk — $25/月〜、**月間 100 万以上の認証リクエスト**処理
- 競合空白: パスワードレス認証 SaaS は月 $23〜と高価。¥500 以下で使える選択肢がない。Supabase Auth は Supabase との縛りがある

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月 100 MAU まで・Magic Link のみ |
| モデル | 月額 |
| 価格 | ¥490/月（1,000 MAU）、¥1,480/月（10,000 MAU） |

**主な機能**
- Magic Link メール認証（npm パッケージ 1 行で組み込み）
- Google / GitHub OAuth ログイン
- ユーザー管理ダッシュボード
- Webhook でユーザー登録イベント通知
- SDK: Next.js / Express / Hono 対応

**AI活用**
- 不審なログインパターン（同一 IP からの大量リクエスト）を Claude Haiku で検出してアラート

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| Auth0 | 中 | 高い・設定が複雑 |
| Clerk | 高 | 機能豊富だが $25/月〜 |
| Supabase Auth | 中 | Supabase との縛り |
| NextAuth.js | 低 | ライブラリなので自前 DB 管理が必要 |

**✅ 結論:** 高すぎる→安価代替パターン。Clerk の $25/月に対して ¥490/月という差別化。Next.js + Resend + Neon で個人が作れる規模。認証は責任が重いためセキュリティレビュー必須

### 🌐 5. 英語技術記事 → 日本語 3 行要約 Chrome 拡張｜スコア: 68

**概要**
Hacker News・dev.to・GitHub README などの英語技術記事をワンクリックで日本語 3 行要約する Chrome 拡張機能。英語記事を読みたいが時間がない日本の開発者向け。

**市場**
- ターゲット: 英語技術記事に触れたいが時間がない日本の開発者
- 参考: DeepL Chrome 拡張 — 無料で普及。ただし「全文翻訳」のみで「要約」機能がない
- 競合空白: 「全文翻訳」は DeepL でできる。「3 行要約 + 技術用語を保持した日本語化」というニーズに特化したツールがない

**収益モデル**
| 項目 | 内容 |
|------|------|
| 無料版 | 月 30 件まで |
| モデル | 月額 |
| 価格 | ¥290/月（無制限） |

**主な機能**
- 右クリック or サイドパネルで記事を 3 行で要約
- 技術用語を保持したまま日本語化
- Hacker News のコメントを日本語でサマリー
- GitHub README の「何をするプロジェクトか」を 1 行表示
- 要約した記事をメモとして保存

**AI活用**
- Claude Haiku で要約（1 記事あたり $0.001 以下）
- 技術用語リストを参照して誤訳を防ぐ（Claude に渡すシステムプロンプトで対応）

**競合分析**
| 競合 | 脅威度 | 弱点 |
|------|--------|------|
| DeepL 拡張 | 中 | 全文翻訳のみ・要約機能なし |
| ChatGPT 拡張 | 中 | 汎用すぎてワンクリックでない |
| Google 翻訳 | 低 | 精度が低い・要約機能なし |

**✅ 結論:** 低コストで始められる小品。¥290/月でも 1,000 ユーザーで月 29 万円。Claude Haiku でコストをゼロに近づけられる。Chrome Web Store の審査待ち（1〜2 週間）に注意
